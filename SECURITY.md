# Security policy

Do not open a public issue for leaked credentials, private dataset paths, unpublished evidence URLs, or sensitive provenance records. Contact the repository maintainer privately through the correspondence address in `paper/metadata.tex`.

The repository intentionally excludes secrets, raw image data, private evidence bundles, checkpoints, and the final PTE. If any restricted object is committed, revoke exposed credentials where applicable, remove the object from Git history, and publish a correction note.
