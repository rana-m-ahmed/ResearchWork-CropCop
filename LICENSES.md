# Licence and redistribution map

This is a multi-licence research repository. Public availability and redistribution rights are treated as separate questions.

| Material | Licence / redistribution status |
| --- | --- |
| Python, shell scripts, CI workflows and sanitized notebooks | MIT License (\`LICENSE\`) |
| Original manuscript/supplement source, documentation, diagrams and derived research tables | Creative Commons Attribution 4.0 International (\`LICENSES/CC-BY-4.0.txt\`) |
| Third-party pretrained model code/weights | Governed by original upstream licences; not relicensed here |
| CropCop consolidated source-image corpus | Not redistributed by this repository; individual source datasets remain subject to provider terms |
| Final R07-S1 checkpoint | Identity-bound but not redistributed pending upstream/licence review |
| FP32 / INT8 ExecuTorch PTE binaries | Identity-bound but not redistributed pending licence/redistribution review |
| Complete Track-B private evidence archive | Identity-bound; not distributed in ordinary public Git history pending release/privacy/licence review |
| Public Track-C measurement CSVs and original derived tables | Repository-authored research evidence; distributed under the documentation/table boundary above unless a file-specific notice overrides |

A file-specific notice overrides this table when present. No licence in this repository grants rights to third-party source images, third-party pretrained checkpoints, private evidence bundles or other assets not owned/licensed for redistribution by the authors.
