# Limitations

1. Internal leakage-controlled evaluation is not external field validation.
2. Source-level provenance and redistribution rights are incomplete for the image corpus.
3. The label space mixes disease specificity and visual target types.
4. The main training lineages use one archived seed.
5. Matched causal controls for DINOv3 pretraining and distillation are absent.
6. Physical-device execution remains pending.
7. The historical mobile training configuration is not fully recoverable in human-readable form.
