# Restricted evidence vault boundary

The following are retained outside public Git history:

- raw image corpus and manifests containing private/local paths;
- full dataset/model/quantisation evidence ZIPs;
- checkpoints, converted graphs, PTE, raw logits, and row-level prediction archives;
- credentials, tokens, private URLs, and workstation/Kaggle paths.

The public repository records artifact names, roles, sizes, SHA-256 values, and curated derivatives. Access is not implied by this inventory.
